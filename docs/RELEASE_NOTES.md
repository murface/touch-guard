# v0.1.2 — first public beta

A community experiment for sweat-induced accidental touchscreen input on an Original Peloton Bike with Android 11.

- Clear accessibility overlay catches taps while leaving the underlying app visible.
- Default five-second Volume Down hold toggles protection ON and OFF; optional two-button mode.
- First-session 30-second safety test, then 30/60/90/120-minute maximum durations.
- Pentagon icon, original cycling illustration, and clearer service/protection status.
- “Touch Guard is ON — Sweat away and get that PR!”
- Hardware shortcut, three-finger hold, timeout, screen-off, and connected-computer escape paths.
- No internet permission, analytics, screen-content retrieval, rooting, or Peloton app modification.

This beta has passed touch-interception and hardware-toggle checks on one tablet. Full workout playback and other devices are unverified. See `docs/TESTING.md`. Public APK updates retain the same signing certificate as the initial local test build; no signing keys are distributed.
